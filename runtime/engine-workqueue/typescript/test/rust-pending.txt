# the engine's Node-API addon (ENGINE_IMPL=rust; D58, milestone 12). The
# engine's scripts/rust-ratchet.mjs runs each test file so under Node.js and
# Bun (`bun run test:rust`, --package): a file that fails and is not listed
# fails the run, and so does a listed file that passes, so the list only
# shrinks. A line is a file under test/, then the runtimes it is pending on
# when not both (node, bun), then why.
#
# test/helpers.ts opens the Rust engine with this package's seven behaviors
# by name, which the addon registers in Rust. What the files below wait for
# is milestone 7b's, the first named on each line first:
#
#   storage    raw SQL on the engine's file (engine.storage): a test reads
#              the behaviors' tables and columns, or makes a copy stale
#   bridge     a behavior written in TypeScript: test/fixtures.ts's
#              test.Gate, test.Lock, test.Signal and Budget stand-in,
#              queue-exclusion's counting() wrappers of Queue and Budget;
#              a value driver (values.driver) or an id source (ids)
#   watch      events.watch over the engine's notifier, which the event
#              stream an idle worker wakes on waits on
#
# No test that runs here fails on what the Rust engine does.
