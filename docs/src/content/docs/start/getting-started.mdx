This page takes one small schema from source to working code. The acme
shop shows prices to shoppers in more than one currency, so it declares a
`Price` type once, and superschematic generates packages in Go,
TypeScript, Python and Rust that decode and validate it the same way.

The schema is the `shop-common` service of `examples/acme-shop`, the
project the [first project](/superschematic/first-project/) tutorial
builds out. Every file on this page is quoted from that directory, and
`examples/acme-shop/scripts/check.sh` builds and tests it on every pull
request. You can follow along there or copy the files into a project of
your own.

## Build the CLI

Set up the checkout as [Prerequisites](/superschematic/start/prerequisites/)
describes, then build the binary and put it on your `PATH`:

```sh
make build
export PATH="$PWD/bin:$PATH"
superschematic --help
```

The binary has the core's six commands: `build`, `build-all`, `migrate`,
`format`, `json-schema` and `behaviors`. The [CLI reference](/superschematic/reference/cli/)
lists their flags.

## Lay out a schemas root

superschematic reads a schemas root: a naming file, a TypeScript
configuration and one directory per service.

<FileTree>
- schemas/
  - superschematic.toml names and coordinates of the generated packages
  - tsconfig.base.json where schema files find their imports
  - services/
    - shop-common/
      - schema.config.ts the service's kind and outputs
      - package.json
      - tsconfig.json
      - src/
        - index.ts
        - price.schema.ts the types
</FileTree>

## Write the schema

<Snippet file="schemas/services/shop-common/src/price.schema.ts" />

- An abstract class declares an object type and an `enum` an enum. The
  classes are abstract because nothing runs them: the compiler reads their
  declarations.
- `Generic.Int64` is a scalar from
  [superscalar](https://github.com/parable-work/superscalar). It is
  `GenericInt64` in both Go, where it is an `int64`, and TypeScript, where
  it is an alias of `number`. superscalar
  has about forty scalars (email addresses, UUIDs, slugs, date-times) that
  parse and validate the same way in every language.
- The comment above `Price` becomes its documentation in every generated
  language.

## Configure the service

<Snippet file="schemas/services/shop-common/schema.config.ts" />

`kind` says what the schema describes. A `General` schema holds plain
types; the other core kinds are `DB` (tables) and `API` (routes).
`outputs.types` lists the languages to generate types in: Go, TypeScript,
Python or Rust.

The two `tsconfig` files let the compiler resolve the schema's imports.
`tsconfig.base.json` at the schemas root maps the authoring packages and
superscalar to their sources, since none of them is published yet:

## Name the generated packages

`superschematic.toml` gives every generated package its coordinates. The
acme shop publishes Go modules under `example.com/acme` and npm packages
under the `@acme` scope:

<Snippet file="schemas/superschematic.toml" from="go_module_root" to="package_author" />

A key left out keeps its default, so the file can start empty. The
`[paths]` table below these keys points the generated packages' path
dependencies at your checkout until the runtimes are published. The
[naming reference](/superschematic/reference/naming/) lists every key.

## Build

From the directory that holds `schemas/`:

```sh
superschematic build schemas/services/shop-common
```

<Snippet file="testdata/generated/logs/build-shop-common.txt" />

Output goes to `schemas/dist`. The first build also writes
`src/service.generated.ts` and exports it from `src/index.ts`: a handle
other services import when they depend on this one. Commit both; later
builds report the sentinel up to date.

<FileTree>
- schemas/dist/types/
  - go/shop-common/ the Go module example.com/acme/types/go/shop-common
    - go.mod
    - types.go
    - enums.go
    - scalars.go
  - typescript/
    - package.json a Bun workspace of every generated types package
    - shop-common/ the npm package @acme/shop-common-types
      - types/
      - validators/
      - index.ts
  - python/shop-common/ the Python package acme_types_shop_common
  - rust/shop-common/ the crate acme-shop-common-types
</FileTree>

## Use the types

Decoding checks every field: a value of the wrong JSON type fails, and so
does a currency outside the enum.

<Tabs syncKey="lang">
  <TabItem label="Go">

    require it and point a `replace` line at the build output, as
    `examples/acme-shop/go/go.mod` does:

    <Snippet file="go/go.mod" from="example.com/acme/types/go/shop-common =>" />

    install in more detail.
  </TabItem>
  <TabItem label="Python">
