This tutorial grows the `Price` type from
[Getting started](/superschematic/start/getting-started/) into a small
shop: a database of products, an API over it served in Go, and a
storefront API served in TypeScript. Each API gets a client SDK generated
from the same schema as its server.

| Part | Service | What you get |
| --- | --- | --- |
| [Model the database](/superschematic/first-project/database/) | `shop-db` | Postgres DDL, a Go ORM, Go and TypeScript types |
| [Serve and call it from Go](/superschematic/first-project/go-api/) | `shop-api` | a Go server, OpenAPI, a Go SDK and a TypeScript SDK |
| [Serve and call it from TypeScript](/superschematic/first-project/typescript-api/) | `shop-storefront` | a TypeScript server and a TypeScript SDK |
| [Build the whole tree](/superschematic/first-project/build-the-tree/) | every service | one build in dependency order, and a cache |

The two API parts are independent. Do the one for the language you work
in, or both to see one schema serve two stacks.

## The project

The finished project is `examples/acme-shop`. Every snippet in these pages
is quoted from it, and `examples/acme-shop/scripts/check.sh` builds it
with the core binary, compiles the generated Go, type-checks the
generated TypeScript and runs the tests in Go, TypeScript, Python and
Rust. `shop-orders` is not part of the tutorial; the
[guides](/superschematic/guides/modeling-types/) use it. They serve it in
Go, and again with the generated
[Rust server](/superschematic/guides/api-routes/#the-rust-server), whose
implementations a [Topcoat app](/superschematic/guides/topcoat/) also
calls from its pages.

    - check.sh

To follow along, work in that directory with the CLI on your `PATH`, or
start your own schemas root as Getting started did and add each service as
you go.

## How the services find each other

A schema imports another service's types by package name. Each service has
a `package.json` naming it (`@acme/shop-db`), and `tsconfig.base.json`
maps every `@acme/*` name to that service's `src/index.ts`:

```json
"@acme/*": ["./services/*/src/index.ts"]
```

A service's `src/index.ts` exports its types and the handle the build
writes to `src/service.generated.ts`. `shop-api` then writes
`import { Product } from "@acme/shop-db"`, and the loader resolves it to
`shop-db`'s schema.
