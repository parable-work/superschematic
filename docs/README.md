# superschematic docs site

Source for https://parable-work.github.io/superschematic/. Built with
[Starlight](https://starlight.astro.build/) on Astro; versions are pinned
exactly in `package.json`. The site is deployed by the `docs-deploy` job of
`.github/workflows/release.yml` on every `vX.Y.Z` tag once the repository is
public. Pull requests also build the site (the `docs` job in `ci.yml`); that
is a recorded deviation from superscalar, which only builds docs in
`release.yml` (see `docs/DECISIONS.md`, D9).

`docs/DECISIONS.md` is the decision log for this repository,
`docs/extension-model.md` is the design of the extension seam and
`docs/stack-model.md` is the design of the stack model (D26). None is a
Starlight page; source comments cite them by path.

## Local development

Node 22.12 or newer (CI uses the `NODE_VERSION` pin in `tools.env`).

```
cd docs
npm install
npm run dev       # http://localhost:4321/superschematic/
npm run build     # writes docs/dist/
npm run preview   # serves docs/dist/
```

`npm run build` fails on a broken internal link (the
`starlight-links-validator` plugin) and on a sidebar entry that points at a
page that does not exist. Fix the page rather than the validator.

## Layout

```
docs/
  astro.config.mjs        site URL, base path, sidebar groups, edit links
  src/content.config.ts   Starlight content collection
  src/content/docs/       one Markdown or MDX file per page
    index.md              overview
    start/                prerequisites, getting started, how it works
    first-project/        the tutorial over examples/acme-shop
    guides/               one guide per area: types, tables, routes, auth, SDKs, the engine, its behaviors and work queues
    install/              per-language pages (the "Languages" group)
    extending/            write an extension, deploy, platform
    reference/            naming file, CLI, one page per feature
    404.md                not-found page, emitted as dist/404.html for GitHub Pages
  src/components/Snippet.astro  quotes a file of examples/acme-shop or examples/engine-notes
  src/lib/snippet.ts      picks the declaration or line range a page quotes
  src/content/i18n/en.json  empty UI-string overrides; keeps the i18n collection non-empty
  DECISIONS.md            repository decision log (not a Starlight page)
  extension-model.md      extension seam design (not a Starlight page)
  stack-model.md          stack model design (not a Starlight page)
```

Links inside pages are written with the `/superschematic/` base included, for
example `/superschematic/install/go/`, because the site is served under that
path on GitHub Pages.

## Writing pages

Plain ASCII, sentence-case headings, no em dashes. Every page starts with a
frontmatter block carrying `title`, `description` and `sidebar.order`; the
sidebar groups are autogenerated from the directory names in
`astro.config.mjs`. Second person, present tense.

## Quoting example code

A page that shows code from `examples/acme-shop` or `examples/engine-notes`
quotes it instead of copying it. Make the page `.mdx` and use the `Snippet`
component:

```mdx
import Snippet from '../../../components/Snippet.astro';

<Snippet file="schemas/services/shop-db/src/shop.schema.ts" symbol={['User', 'Session']} />
<Snippet file="testdata/generated/sql/shop-db/create.sql" from="CREATE TABLE product (" to="COMMENT ON TABLE product" />
```

`file` is a path under `examples/acme-shop`, or under the example that
`example` names (`example="engine-notes"`). `symbol` names top-level
declarations (a TypeScript class, interface, enum, function or const; a Go
type or func, or a Go method as `Type.Method`; a Rust struct, enum or fn;
a Python class or def), with the comments, decorators and attributes
directly above each. `from` and `to` quote the lines from the first one
containing `from` to the next one containing `to`. With neither, the whole
file is quoted. A name or anchor that matches nothing fails the build.
Schema files cannot carry region markers: the loader turns every comment
above a declaration into its description.

`examples/acme-shop/scripts/check.sh` builds, compiles and tests
everything a page can quote, and the `acme` CI job runs it. Generated code
is quoted from `examples/acme-shop/testdata/generated/`, committed copies of
selected files of the build output (this site builds without Go or the
superscalar checkout). To quote another generated file, add it to the
`QUOTED` list in `check.sh` and run `UPDATE=1 examples/acme-shop/scripts/check.sh`.
The check fails when a copy goes stale. `examples/engine-notes/scripts/check.sh`
type-checks and tests what the engine guide quotes, and the `typescript` CI
job runs it.
